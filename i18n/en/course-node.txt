**Key ideas**
- **Node.js** runs JavaScript on servers and computers (no DOM, no `window`).

**Key ideas**
- **Middleware** `(req, res, next)` runs before routes: logging, auth, parsing, CORS. Order matters.

app.use(express.json());          // parse JSON bodies
app.use((req, res, next) => {     // log every request

- **Authentication**: who is this user? (log in)
- **Authorization**: what may they do? (admin only?)

Two common approaches:
- **Sessions**: the server stores the login and gives the browser a cookie
- **Tokens (JWT)**: the server signs a token; the client sends it in `Authorization: Bearer ...`

Never store plain passwords: hash them with **bcrypt** or **argon2**. Many teams use services like Auth0, Clerk or Supabase Auth.
