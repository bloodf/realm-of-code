`ref` creates **reactive** state. When it changes, the template updates:

```
<script setup>
import { ref } from "vue";
const potions = ref(0);
</script>

<template>
  <button @click="potions++">Brew</button>
  <p>Potions: {{ potions }}</p>
</template>
```

In the template you write `potions`. In the script you must use `potions.value`. `@click` is short for `v-on:click`.

A child component declares its **props** with `defineProps`:

