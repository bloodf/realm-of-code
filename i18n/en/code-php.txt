Never print user text directly into HTML. `htmlspecialchars()` turns `<` into `&lt;` so the browser shows it as text:

```
$name = "<b>Bors</b>";
echo "<p>Hello " . htmlspecialchars($name) . "</p>";
// <p>Hello &lt;b&gt;Bors&lt;/b&gt;</p>
```
Other useful functions: `trim()`, `strtolower()`, `ucfirst()`, `strlen()`.

class Member {
