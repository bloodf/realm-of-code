**Ideias principais**
- Uma **API** é um jeito de programas conversarem. APIs web respondem requisições HTTP com dados (geralmente JSON).
- **REST**: recursos são URLs (`/knights`, `/knights/2`); os métodos dizem a ação: GET (ler), POST (criar), PUT/PATCH (atualizar), DELETE (remover).
- Códigos de status: 200 OK, 201 Created, 204 No Content, 400 Bad Request, 401 Unauthorized, 403 Forbidden, 404 Not Found, 500 Server Error.
- **Cabeçalhos** levam informação extra: `Content-Type: application/json`, `Authorization: Bearer <token>`.
- Query strings filtram: `/knights?house=Lovelace&page=2`.

**Ideas clave**
- Una **API** es una forma de que los programas hablen entre sí. Las APIs web responden peticiones HTTP con datos (normalmente JSON).
- **REST**: los recursos son URLs (`/knights`, `/knights/2`); los métodos dicen la acción: GET (leer), POST (crear), PUT/PATCH (actualizar), DELETE (borrar).
- Códigos de estado: 200 OK, 201 Created, 204 No Content, 400 Bad Request, 401 Unauthorized, 403 Forbidden, 404 Not Found, 500 Server Error.
- Las **cabeceras** llevan información extra: `Content-Type: application/json`, `Authorization: Bearer <token>`.
- Las query strings filtran: `/knights?house=Lovelace&page=2`.

**Ideias principais**
- `const res = await fetch(url);` e depois `const data = await res.json();`
- O `fetch` só lança erro em falha de rede. Confira `res.ok` (status 200–299) para erros HTTP.
- Enviar dados: `fetch(url, { method: "POST", headers: { "Content-Type": "application/json" }, body: JSON.stringify(obj) })`.
- Envolva em `try/catch`. Nas interfaces, mostre os estados de **carregando**, **erro** e **vazio**.
- **CORS**: os navegadores bloqueiam requisições para outros domínios, a menos que o servidor permita.
~~

**Ideas clave**
- `const res = await fetch(url);` y luego `const data = await res.json();`
- `fetch` solo lanza error ante un fallo de red. Comprueba `res.ok` (estado 200–299) para los errores HTTP.
- Enviar datos: `fetch(url, { method: "POST", headers: { "Content-Type": "application/json" }, body: JSON.stringify(obj) })`.
- Envuélvelo en `try/catch`. En las interfaces, muestra los estados de **carga**, **error** y **vacío**.
- **CORS**: los navegadores bloquean las peticiones a otros dominios salvo que el servidor lo permita.

- **carregando**: mostre um spinner ou um esqueleto
- **erro**: explique e ofereça tentar de novo
